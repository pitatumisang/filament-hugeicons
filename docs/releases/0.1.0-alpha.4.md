# v0.1.0-alpha.4

Status: published on 2026-11-10 from commit `f3286e2ae2eb4dce83de3390e6ba66c4a9c19f16`.

## Release notes

Filament Hugeicons now supports Filament `^5.0` with PHP `^8.2`, including applications locked to Filament 5.10.1. Both direct enum usage and optional default icon replacement work across the supported major.

- Keep the existing 6,839-case `Hugeicon` enum and native Blade Icons rendering.
- Use native alias normalization when the installed Filament exposes it; older registries preserve exact alias strings. Use Filament's alias constants for overrides.
- Preserve opt-in application-wide replacement, developer override priority, unmapped fallback, conflicting declaration checks, and scoped registry replay.
- Validate installed alias inventories independently of the pinned Filament 5.11.2 reference report.
- Test minimum/latest Filament on PHP 8.2–8.4 with Laravel 12, plus exact 5.10.1 regression and 5.11.2 reference-report lanes.

Install or upgrade with:

```sh
composer require enigmainc/filament-hugeicons:0.1.0-alpha.4 -W
```

Dependencies: PHP `^8.2`, Filament `^5.0`, Spatie Laravel Package Tools `^1.16`, and Blade Hugeicons exactly `2.1.0`. Laravel 12 is the tested Laravel version. Filament 4 is unsupported. Public APIs and mappings may change before v1.0.0.

Replacement remains disabled by default and application-wide when enabled, including panels without the plugin. Per-panel/per-tenant policies are unsupported; restart long-running workers after configuration changes. Real Octane server behavior remains unverified. Earlier tags, including alpha.3 and its `^5.11.2` requirement, remain unchanged.
