# Preparing v0.1.0-alpha.3

Status: finalizing the release candidate, not yet tagged or published. Includes the current main branch's replacement implementation and latest documentation.

## Draft release notes

Filament Hugeicons now offers optional application-wide replacement of Filament's default icons, alongside its 6,839-case native Hugeicon enum.

- Enable replacement with `FilamentHugeiconsPlugin::make()->replaceDefaultIcons()` or published config. It remains disabled by default; explicit enum usage needs no plugin.
- Apply curated Hugeicons defaults to 81 of the 221 canonical aliases inspected in Filament 5.11.2. Unmapped aliases keep Filament's originals.
- Customize aliases with `overrideAliases()`. Native developer registrations win over fluent overrides, config overrides, and bundled defaults, in that order.
- Validate one bootstrap policy across panels, reject conflicting declarations, and replay package mappings when Filament resets its scoped registry.
- Check generated alias coverage for drift alongside the icon catalog.

**Compatibility change:** requires Filament `^5.11.2` (previous alphas allowed `^5.0`), PHP `^8.2`, and the pinned Blade Hugeicons `2.1.0` catalog. Laravel 12 is the tested Laravel version. Filament 4 is unsupported.

**Scope:** replacement affects the entire application, including panels without the plugin. Per-panel, per-request, and per-tenant policies are unsupported. Restart long-running workers after configuration changes. A real Octane server has not been tested. This is an alpha; APIs, mappings, and catalog identifiers may change before v1.0.0.

After publication, install with:

```sh
composer require enigmainc/filament-hugeicons:0.1.0-alpha.3
```

See [replacement configuration and lifecycle](../default-icon-replacement.md) and the [complete coverage report](../default-icon-coverage.md).
